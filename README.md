# DIAN115 REMUX 同步插件（开发中）

**当前仅完成纯 Go 筛选与队列核心，尚无可安装插件包、真实服务适配器或已启用的定时任务。**

## 已确认需求

- 来源：https://madow.tv/remux ，只选择 REMUX 的 115 分享。
- 每 6 小时检查一次；计划使用 DIAN115 manifest jobs（`0 */6 * * *`），不依赖浏览器或 Codex 常驻。
- 跨已配置 Emby 实例的全部电影、剧集库去重；已存在的剧目整体跳过，不承担旧插件的缺集补全功能。
- 同一 TMDB / 类型，先选不重复的季集组合最多的分享，再选字节数最大的分享。集数、大小或身份不明时暂缓该组。
- 单次、每日积分均无限制（当前开发配置），但任务和解锁结果仍须留痕。
- 串行转存及整理，全部结束后刷新 Emby，逐条核实入库。待入库剧目参与后续扫描去重。

## 已实现

`core/planner.go` 要求完整目录、全部 Emby 库完整分页结果；按 TMDB 去重，同名同年但缺少 TMDB 的现有条目暂缓判断。排序与页面顺序无关，未知候选不能被静默忽略。

`core/queue.go` 采用以下状态流：

`queued → 再查 Emby → absent → unlock → receive → organize → 批次刷新 → verify_ingestion → ingested`

`core/runner.go` 在外部操作前先要求存储原子 CAS 成功；恢复时调用结果核对接口，不直接重复解锁/转存。模糊结果保留 Pending。某条入库慢时轮换核验其他条目。

这些是可测试的内部接口，不代表 Madow/DIAN115 网络接口已经实现。生产接入仍须实现持久化 Store、Adapter、真实分页、数据校验、宿主调度、授权界面及后台唤醒。当前核心以结构化确认结果为输入，不能自行证明外部转存或入库成功。

## 接入前提与待办

1. 本项目尚未取得已审批的 Madow 开发者应用 SDK，当前不具备生产调用能力。
2. [官方 OpenAPI v2 文档](https://madow.tv/openapiv2) 要求用户 Key **和已审批开发者应用 SDK** 同时具备。不能复用、提取或仿造 DIAN115 内置应用身份。浏览器登录不能代替 SDK。
3. 文档列出 `POST /api/portal/openapi/list-shares`（资源 ID 或 TMDB 定位、支持分页过滤）和 `POST /api/portal/openapi/unlock`。未找到枚举整个 REMUX 目录的开放接口。不能据此声称可抓取全部约 1.5 万条资源。
4. 需要已审批 Go/Python SDK 的合法本地包，以及全目录枚举接口的确认；或者由 DIAN115 官方提供可供插件调用的 Madow 目录、查询、解锁接口。

不创建/删除现有 Key，不提交虚构开发者申请，不读取宿主内部凭据，不改变宿主全局积分设置。取得 SDK 后，应通过宿主安全凭据绑定配置用户 Key，不写入源码、普通队列或日志。
